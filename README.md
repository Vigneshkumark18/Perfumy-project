# Perfumy Website

## 📌 About the Project

Perfumy is a simple perfume-themed website created using HTML5 and CSS3. The website showcases perfume products in an organized and 
attractive layout. This project helped me practice webpage structuring, CSS styling, product presentation, and layout design while 
improving my front-end development skills.

## 🛠️ Technologies Used

* HTML5
* CSS3

## ✨ Features

* Simple and clean user interface
* Perfume product display section
* Product descriptions and images
* CSS-based styling and layout
* Organized webpage structure

## 🎯 Purpose

The main purpose of this project is to strengthen my HTML and CSS fundamentals and gain practical experience in designing product-based websites.

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open the `index.html` file in your web browser.
